# Puzzle bank

Generated by `npm run build:bank` from the Sudoku Exchange puzzle bank. Do not edit the JSON by hand.

- **Source**: https://github.com/grantm/sudoku-exchange-puzzle-bank at commit `d8c8ebaee0c08c412cfba96af1923dfa61c83317`
- **License**: the source data set is dedicated to the public domain (Unlicense, `LICENSE.txt` in the source repository). Crediting it is a courtesy, not a requirement.
- **Ratings**: Sukaku Explainer ratings from the source (`se`). Levels bucket them as very-easy below 1.5, easy below 2.0, medium below 2.7, hard below 4.5, expert below 7.1, extreme from 7.1.
- **Contents**: 5,000 puzzles per level, spread evenly across that level's rating values, each verified to have exactly one solution.
- **Row format**: `[id, puzzle, se]`. `id` is the source's 12-character hash of the puzzle, `puzzle` is 81 digits with `0` for empty cells.
- **Reproducible**: the commit and the sampling seed are fixed in `scripts/build-bank.ts`, so rerunning it produces identical files.
